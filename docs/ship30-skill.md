# Ship 30 for 30 ? Writing Skill

## Purpose
Turn podcast-grounded insights into a useful, skimmable long-form draft when
the user requests a Ship 30 for 30-style post.

## Structure
1. Start with a specific hook, tension, surprising observation, or concrete
   problem. Avoid generic openings.
2. Establish context and why the reader should care.
3. Develop one central idea through a logical narrative progression.
4. Use short sections with descriptive headings, concise paragraphs, and
   bullets where they improve scanning.
5. Include a concrete example or actionable framework grounded in the supplied
   transcript evidence.
6. End with a clear takeaway or practical next step.

## Voice and quality
- Prefer specific, plain language and active verbs.
- Make one main argument rather than stacking unrelated tips.
- Use bold sparingly to emphasize key ideas.
- Avoid invented anecdotes, statistics, quotations, or episode details.
- Cite transcript-grounded claims with the available source IDs.
- Distinguish direct evidence from recommendations or interpretation.
- Remove repetition, filler, empty motivational language, and vague claims.

## Length and review
For a full Ship 30 for 30-style article, target approximately 1,250 words
unless the user requests another length. Review the narrative progression,
specificity, skimmability, factual support, and takeaway before returning it.

## Important limitation
This document encodes a working style guide. If the assignment requires
reading a particular external writing guide, read and incorporate that guide
before claiming the requirement is fully satisfied.
